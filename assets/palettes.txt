# INFINITE BEST -- CGB palettes
#
#   @bgpal  <n> <NAME> <c0> <c1> <c2> <c3>
#   @sprpal <n> <NAME> <c0> <c1> <c2> <c3>
#
# Colours are 24-bit #rrggbb; the generator converts to RGB555 (>>3).
# c0 = background, c1 = dim, c2 = bright, c3 = hot highlight.
# Every BG palette MUST share c0 (deep navy) so the screen is coherent.
# Sprite c0 is transparent (value unused).
